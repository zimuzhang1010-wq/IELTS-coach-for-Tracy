
# AI IELTS Speaking Coach

An AI-powered speaking practice tool designed to help students improve fluency, answer structure, and confidence using structured teaching frameworks.

## Overview
This project transforms real classroom teaching methods into an AI-powered learning system. It helps students not only practice speaking, but also learn how to structure answers effectively.

## Target Users
- IELTS students (but this one is specifically for one of my students who's going to take the exam soon)
- Beginner to intermediate learners
- Students with weak vocabulary and low confidence

## Key Differentiator
Unlike typical AI speaking tools, this system integrates structured frameworks used in real teaching:

- **PPF (Part 2):** Past – Present – Future  
- **CRISP (Part 3):** Comparison – Reason – Influence – Supporting Example – Personal Example  

These frameworks help students extend answers and think more logically.

## Features
- IELTS Speaking Part 1, 2, 3 practice  
- AI-generated questions  
- Real-time feedback (fluency, grammar, vocabulary)  
- Framework-based answer guidance  
- Vocabulary reinforcement  

## Impact
This project turns personal teaching experience into a scalable AI-powered product, improving student confidence and speaking performance.
